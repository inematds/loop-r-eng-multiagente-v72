Aula 1 · 15 min

Quando NÃO usar multiagente

Cada agente a mais lê o contexto de novo, gasta a própria cota e precisa ser coordenado. Na maior parte das tarefas de código, um agente só, ou subagentes que devolvem pouco, rende mais. Nesta aula você decide antes de abrir o segundo agente, com uma matriz de sinais que roda como script.

Começar a aula

Nesta aula você vai

  1. 1Quanto custa um time: os números publicados e o que eles medem
  2. 2Os 6 sinais de sequência e os 7 de paralelo
  3. 3A regra da diferença de 2 pontos e o híbrido
  4. 4A matriz como script, com as suas tarefas

Objetivo: decidir entre um agente, sequência, paralelo ou híbrido pela matriz de sinais, antes de abrir o segundo agente.

01 · Antes do segundo agente

Clique em cada etapa. A matriz é do kit arquiteto-de-execucao (agenteexecuta).

Clique em cada bloco do diagrama para ver o que ele faz.

A matriz é ponto de partida, não medição. Ela evita o reflexo de abrir agentes porque dá.

02 · O custo que não aparece no pedido

O que está publicado, com data, e o que cada número mede.

1. Tokens

No post sobre o sistema de pesquisa da Anthropic (13/06/2025): agentes gastam cerca de 4× os tokens de um chat, e sistemas multiagente cerca de 15×. Os dados são deles, num produto de pesquisa.

A doc de agent teams do Claude Code diz o mesmo sem número: um time usa significativamente mais tokens que uma sessão, e o gasto cresce com cada colega ativo.

2. Ganho

No mesmo post, líder Opus 4 com subagentes Sonnet 4 superou o Opus 4 sozinho em 90,2% na avaliação interna de pesquisa deles, em perguntas de amplitude (muitas direções independentes).

O próprio post avisa: a maioria das tarefas de código tem menos partes paralelizáveis que pesquisa, e agentes ainda coordenam mal em tempo real. Não há medição deste curso que transfira esse ganho para o seu código.

3. Contexto

A matriz do arquiteto-de-execucao mostra a conta (exemplo ilustrativo, não medido): três agentes que leem 50 mil de contexto e trabalham 20 mil cada somam 210 mil; um agente que reaproveita o contexto faz o mesmo com 110 mil.

A economia vem de não repetir a preparação. Paralelo vale quando cada tarefa tem contexto pequeno.

4. Limites

Nenhum subagente sem tarefa, entrada e saída explícitas; no máximo um nível de delegação, salvo necessidade clara; duas tentativas por item antes de repensar; não reprocessar item aprovado.

Trabalho mecânico (converter, renderizar, rodar teste) vai para script, não para agente.

03 · A matriz como script

Escreva os sinais de cada tarefa num arquivo; o script soma e decide. Nada de modelo: roda de graça.

# decide.py — matriz de decisão do arquiteto-de-execucao (inematds/agenteexecuta), em código
# Uso: python3 decide.py tarefas.txt
# tarefas.txt: um bloco por tarefa; "# nome" abre o bloco; depois, um código por linha:
#   S1..S6 = sinais de sequência, P1..P7 = sinais de paralelo,
#   simples = tarefa pequena (não aplica a matriz), erro-caro = custo de erro alto
import sys

SEQ = {"S1": "depende da saída anterior", "S2": "contexto compartilhado grande",
       "S3": "decisões precisam ficar consistentes", "S4": "erro inicial contamina várias tarefas",
       "S5": "juntar versões divergentes sai caro", "S6": "uma etapa ensina a seguinte"}
PAR = {"P1": "tarefas independentes", "P2": "entradas congeladas",
       "P3": "cada saída se valida sozinha", "P4": "trabalho mecânico ou determinístico",
       "P5": "contexto pequeno por tarefa", "P6": "urgência alta", "P7": "há máquina sobrando"}

def decide(nome, cods):
    print(f"# {nome}")
    for c in cods:
        if c not in SEQ and c not in PAR and c not in ("simples", "erro-caro"):
            print(f"aviso: código desconhecido '{c}' (ignorado)")
    if "simples" in cods:
        print("decisão: direto (um agente só, sem matriz)\n")
        return
    s = sum(c in SEQ for c in cods)
    p = sum(c in PAR for c in cods)
    if abs(s - p) >= 2:
        d = "sequencial" if s > p else "paralelo"
    else:
        d = "híbrido"
    print(f"sequência: {s} · paralelo: {p} · diferença: {abs(s - p)}")
    print(f"decisão: {d}")
    if "erro-caro" in cods:
        print("custo de erro alto: planejamento e revisão centralizados")
    print()

nome, cods = None, []
for linha in open(sys.argv[1], encoding="utf-8"):
    linha = linha.strip()
    if linha.startswith("#"):
        if nome:
            decide(nome, cods)
        nome, cods = linha.lstrip("# ").strip(), []
    elif linha:
        cods.append(linha.split()[0])
if nome:
    decide(nome, cods)

A conversão de 500 arquivos é paralelo mecânico: script com vários trabalhadores e conferência por amostra no centro (é a aula 3). A pesquisa empatou: o primeiro segmento roda sozinho, os outros três em paralelo.

Código em minúscula não conta. O script avisa em vez de somar calado, e a decisão muda. Capturado no mesmo dia:

# migrar o banco

Com S1 certo, seria sequência 2 × paralelo 1, ainda híbrido, mas por um motivo que você escolheu. Confira grep -c "^aviso:" decisao.md → 0.

06 · Em três frases

Time custaCada agente relê o contexto e gasta a própria cota; publicado: cerca de 15× tokens de um chat.
Matriz antesSinais de sequência × paralelo; diferença de 2 decide, menos que isso é híbrido; erro caro centraliza.
Simples é diretoTarefa pequena não passa pela matriz, e trabalho mecânico vai para script.

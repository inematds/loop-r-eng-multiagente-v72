Lesson 2 · 18 min

Subagents: clean context, short return

A subagent does the noisy part in its own context window and returns only the summary. It's worth what doesn't come back: logs, searches, and files the main conversation will never read again. In this lesson you write a read-only subagent with a return of up to 12 lines and actually check the size of what came back.

Start the lesson

In this lesson you will

  1. 1What the subagent receives and what it returns
  2. 2The .claude/agents/[nome].md file and the fields that matter
  3. 3Restricted tools: what the list locks and what only the instruction asks for
  4. 4Fixed-format return with a confidence line

Goal: create a read-only subagent with a return of up to 12 lines and check that its answer fits in the main conversation.

Fork is something else: it inherits the whole conversation (/subtask) and loses input isolation. Good for a side task that needs what has already been said.

02 · The fields that decide

Of the supported frontmatter, four change behavior day to day.

1. description

Claude delegates when the task matches the description. Write when to use it and when not to use it, in one sentence.

A new file in .claude/agents/ takes effect without restarting, except when the agents/ folder didn't exist at the start of the session.

2. tools

List of tools it can use. Without the field, it inherits the conversation's tools. Without Write, Edit and Bash, it writes nothing, no matter how much the model wants to.

disallowedTools with a specifier, like Bash(git push *), removes the whole tool; to block only that command, use permissions.deny.

3. model

Accepts an alias or inherit. Choose by the role's level (lesson 7), not by the name of the day: names change.

The runtime kit uses opus, sonnet and haiku in the three roles; treat that as an example of different levels.

4. Body

The body of the file becomes the system prompt. Put the response format in it: maximum number of lines, path:line as proof, and a final confidence line.

This format lets the orchestrator read 10 summaries without filling its own window.

03 · A read-only explorer

Create the file, check the fields without spending quota, then make a real call.

.claude/agents/explorador.md · in ~/treino-multi
---
name: explorador
description: Searches the project and returns only a summary. Use it to sweep many files without filling the main conversation.
tools: Read, Grep, Glob
model: inherit
---
You are the explorer. Change nothing.
Return at most 12 lines:
1. The answer in one sentence.
2. Up to 8 lines in the format path:line — what is there.
3. Last line: CONFIANÇA alta|média|baixa and what you did not check.
Terminal · no-quota rehearsal: check the project's subagents
cd ~/treino-multi
python3 - .claude/agents/*.md <<'PY'
import sys, re
for f in sys.argv[1:]:
    m = re.match(r"---\n(.*?)\n---", open(f, encoding="utf-8").read(), re.S)
    if not m:
        print(f, "→ SEM frontmatter"); continue
    d = {k.strip(): v.strip() for k, v in (l.split(":", 1) for l in m.group(1).splitlines() if ":" in l)}
    tools = d.get("tools", "(herda todas)")
    escreve = "tools" not in d or any(x in tools for x in ("Write", "Edit", "Bash"))
    print(f"{d.get('name', '?')} · tools: {tools} · model: {d.get('model', '(herda)')} · escreve: {'sim' if escreve else 'não'}")
PY
Terminal · real call (uses a little quota)
cd ~/treino-multi
claude -p "Use o subagente explorador para descobrir onde este projeto define a própria versão e quais arquivos citam essa versão. Repita apenas o resumo que ele devolver, sem comentar." < /dev/null > resposta.md
grep -c "^CONFIANÇA" resposta.md; wc -l < resposta.md

CONFIANÇA alta. Não conferi o que o .gitignore exclui nem os outros números de versão (0.1.0, 0.2.0), e não verifiquei se algum script lê o VERSION.

The ## headings separate the two rounds. Declared cuts: two lines of the translated guide and a final line that the global CLAUDE.md of the capture machine adds. On your machine, wc -l should be between 10 and 15.

The checker marked revisor · … · escreve: sim. The kit file says "Não altere arquivos", but the tool list includes Bash, and Bash writes. The instruction is a request to the model; the tool list is the lock.

revisor · tools: Read, Bash, Grep, Glob · model: haiku · escreve: sim

The reviewer needs Bash to run the criteria. To keep it from actually writing, the way out is sandbox (lesson 5) or a permission rule; guarding against deleting and writing is covered in course 4. And the real call without < /dev/null waits 3 s for stdin and warns: Warning: no stdin data received in 3s.

06 · In three sentences

Worth it for what doesn't come backLogs, searches, and files stay in the subagent's window; only the summary comes back.
A tool is a lockRead, Grep, Glob don't write; Bash does, no matter what the instruction says.
Fixed formatMaximum lines, path:line as proof, and a confidence line, written in the body of the file.

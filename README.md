# Multiagente e Orquestração — Formação LOOP-R Engenharia (curso 3 de 6)

Curso aberto e gratuito do INEMA.CLUB no formato INEMA Learning v7.2, em português, inglês e espanhol:
**https://inematds.github.io/loop-r-eng-multiagente-v72/** · [EN](https://inematds.github.io/loop-r-eng-multiagente-v72/en/) · [ES](https://inematds.github.io/loop-r-eng-multiagente-v72/es/)

Oito aulas para dividir trabalho entre agentes (Claude Code e Codex) só quando paga: quando não usar multiagente, subagentes com retorno curto, fan-out com teto, gerador × avaliador, worktrees e sandboxes, filas sem colisão, o time Claude + Codex e o `time.md` do seu loop. O projeto de treino é um clone do [inema-agent-runtime](https://github.com/inematds/inema-agent-runtime). Toda prática tem ensaio sem gastar cota (agente falso) e termina em "pronto quando: comando → saída esperada"; as saídas mostradas foram capturadas em 19/10/2026 (Claude Code 2.1.303, Codex CLI 0.163.0).

Conteúdo em `conteudo/<idioma>/` (JSON). O HTML é gerado: `python3 gerar.py && python3 validar.py --links` (e `--lang en|es`). Plano das aulas em `PLANO.md`.
